Ice Plant Management System

DjangoMySQLBootstrap

The Problem

An ice plant has to keep production, stock, customer orders, deliveries and sales in step. When these live in separate records, it is hard to know what was made, what is left and what was sold.

Architecture and Tech Stack

A Django web app with five modules, backed by a MySQL relational database. I chose Django for its built-in authentication and ORM, which suit a login-based system with many linked records. I chose MySQL because orders, customers, deliveries and stock are naturally related tables.

My Contributions

I developed the five modules: production logs, inventory, customer orders, deliveries and sales reports. I designed the MySQL database and wrote the Django ORM model relationships that connect all five. I also implemented the login for two roles, admin and staff.

Results and Testing

The system runs as a working application with 5 connected modules and 2 user roles, and it produces sales reports from the stored data.

Face and Hand Tracking Ball Catcher

PythonOpenCVMediaPipe

The Problem

Most games need a keyboard or mouse. I wanted to show that a normal webcam can be the only controller, which makes a game easier to pick up and play.

Architecture and Tech Stack

A Python program that reads a live webcam feed with OpenCV and tracks the hand and face with MediaPipe. I chose MediaPipe because it already provides hand and face tracking, so I could focus on the game rules.

My Contributions

I developed the game, where players use their hand and mouth to catch falling balls. I programmed the collision detection that scores points on safe balls and triggers a penalty when the player touches an exploding ball.

Results and Testing

The game processes the webcam feed in real time and is played with no keyboard or mouse.
